# HTML 原型审阅编辑器（本地试用版）

面向产品经理的本地 HTML 原型文字编辑与组件批注工具。所有项目、草稿、备份和导出文件仅在本机处理。

## 从 Git 克隆后运行（他人使用）

本工具是**本地运行**的：代码跑在使用者自己的机器上，直接读写其本地项目文件夹，不需要任何服务器。

前置条件：安装 Node.js（建议 16 或以上版本）。

```bash
git clone https://github.com/willpengpeng/prototype-editor.git
cd prototype-editor
npm install        # 安装依赖 parse5（已锁定在 package-lock.json）
npm start          # 启动本地服务
```

启动后浏览器自动打开 `http://127.0.0.1:4178`；若未自动打开，手动访问该地址即可。随后在弹出的系统文件夹选择框中挑选一个本地 HTML 原型项目（含 html/css/js/图片的文件夹）开始编辑。

macOS 用户也可直接双击 `启动编辑器.command`，它会自动安装依赖并启动。

### 平台支持说明

- **macOS**：完整支持（含系统文件夹选择对话框、整项目 ZIP 导出、自动打开浏览器）。
- **Windows / Linux**：核心编辑、单文件导出可用，但以下 macOS 专属功能会报错或不生效：
  - 系统文件夹选择对话框 → 改用环境变量指定项目根目录：`HPE_PROJECT=/绝对路径/原型项目 npm start`；
  - 整项目导出为 ZIP（`ditto` 仅 macOS 可用，单文件导出不受影响）；
  - 自动打开浏览器 → 手动访问地址即可。

## 启动

首次使用双击 `启动编辑器.command`。首次启动会安装本地运行依赖，之后会自动打开编辑器页面。

也可以在终端运行：

```bash
npm install
npm start
```

默认地址为 `http://127.0.0.1:4178`。

## 当前试用功能

- 打开包含多个 HTML、CSS、JS 和图片的项目文件夹；
- 保留页面交互并识别 iframe 内的真实来源文件；
- 修改 HTML 静态文字和常用提示属性；
- 单击组件添加、修改、删除批注；
- 批注按左侧当前页面独立管理，切换页面时列表、编号、搜索和导出内容同步切换；
- 鼠标悬停批注编号或批注卡片可查看完整内容；
- 批注卡片保留原有换行；超过 10 行时可点击“查看全文”展开，再点击“收起全文”恢复；
- 右侧批注栏可以收起和重新显示；
- 左侧“项目页面”栏可以收起和重新显示，收起状态会在刷新后保留；
- 本地恢复草稿、撤销和重做；
- 覆盖源文件前自动备份，或另存整个项目副本；
- 导出时可选择“当前页面”或“页面所在文件夹”；当前页面的标准版和批注版均直接导出为单个 HTML，不生成 ZIP；页面所在文件夹的多文件交付仍会自动生成 ZIP。页面的样式、脚本、图片和 iframe 会尽量内嵌到单文件 HTML 中。
- 单文件导出默认写入当前 HTML 源文件所在的文件夹，并使用时间戳避免覆盖源文件；整项目导出会写入项目所在文件夹的上一级，避免递归复制。
- 导出的批注页面可显示或隐藏批注编号，也可展开或收起右侧批注栏。
- 保存和导出批注时仅处理当前页面，其他页面的本地批注保持不变。

## 数据位置

草稿和备份保存在：

`~/Library/Application Support/HTML Prototype Editor/`

除非在界面中选择“覆盖源文件”，编辑器不会修改原项目。
